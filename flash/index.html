T-Dongle-S3 一鍵燒錄

Agent 中控中心引導韌體 26.11.3-engine5.7・不用裝 Arduino

  1. 用電腦版 Chrome 或 Edge 打開這一頁（手機、Safari、Firefox 不行）。
  2. 先把 TF 卡拿出來。按住 Dongle 上的按鈕，再插上電腦，插好後放開。
  3. 按下面的「開始燒錄」→ 選跳出來的裝置（名稱通常有 USB JTAG/serial 或 COM）→「連線」。
  4. 選「安裝」。問要不要清除裝置時，第一次燒錄選清除。
  5. 等進度跑到 100%。拔掉 Dongle，插回 TF 卡，再插上電腦就會開始自動安裝。
這個瀏覽器不支援燒錄，請改用電腦版 Chrome 或 Edge。 請用 https 網址打開這一頁。
燒完後如果出現「連不上裝置」或要你設定 Wi-Fi，不用理它，直接拔掉就好：這個韌體不用 Wi-Fi，燒好後它會變成隨身碟＋鍵盤，網頁就認不得它了。
選裝置時清單是空的：拔掉，確認一直按住按鈕再插一次。

韌體會從 https://raw.githubusercontent.com/AEverhub/USB-AGENT/main/ 下載軟體到 TF 卡。這個韌體還沒有在實機上測過。
