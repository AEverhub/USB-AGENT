T-Dongle-S3 一鍵燒錄

Agent 中控中心引導韌體 26.11.3-engine6.4・不用裝 Arduino

  1. 用電腦版 Chrome 或 Edge 打開這一頁（手機、Safari、Firefox 不行）。
  2. 先把 TF 卡拿出來。按住 Dongle 上的按鈕，再插上電腦，插好後放開。
  3. 在下面選一個版本按「燒錄」→ 選跳出來的裝置（通常有 USB JTAG/serial 或 COM）→「連線」→「安裝」。第一次燒錄問要不要清除，選清除。
  4. 跑到 100% 後拔掉 Dongle，插回 TF 卡，再插上電腦。

一般版

插上就能用：整理 USB、找檔案、把 USB 的檔案拿出來／存回去。

請改用電腦版 Chrome 或 Edge。 請用 https 網址打開這一頁。

開發版開發者

多了：AI 可以看這台電腦的 C:、D: 磁碟、找檔案，把檔案複製或搬運到 TF 卡（用說的就好）；手機連線預設開，手機上也能下載電腦的檔案。

請改用電腦版 Chrome 或 Edge。 請用 https 網址打開這一頁。

插上之後會怎樣

  1. Dongle 先自己看 TF 卡（FAT32、exFAT 都可以）。
  2. 已經設定好（卡上有 AgentCenter\start.bat）→ 直接開 start.bat，輸入 USB 密碼就能用。
  3. 空的卡 → 自動從網路下載安裝，小螢幕顯示進度。
  4. 電腦上的 AI 開好了，按一下 Dongle 的按鈕＝開啟成功 → 綠燈。沒開成功就長按 3 秒（看到「放開＝重新開啟」就放開）重新開啟。之後 Dongle 就協助 AI 找 TF 卡以外（電腦 C:、D:…）的檔案、搬運到 TF 卡，搬運中會提醒「請勿拔除」。
  5. 不用管電腦現在是中文還是英文輸入法：Dongle 用 Alt＋數字鍵盤打字，注音輸入法不會攔截；打完會一直等電腦回應。
  6. 手機連線（開發版預設開）：手機和電腦連同一個 Wi-Fi，掃 Dongle 螢幕上的 QR Code（電腦啟動視窗也有），手機上就能跟 AI 說話、下載電腦 C:、D: 和 TF 卡的檔案、上傳到 TF 卡。
  7. 按鈕：短按＝開好了（綠燈）／之後切換手機 QR Code。長按看螢幕提示、放開時決定——還沒綠燈：3 秒＝重新開啟、6 秒＝下次插上先檢查更新；綠燈之後：5 秒＝安全退出 USB（閃綠燈＝可以拔）；10 秒＝開／關插上自動啟動。
燒完後如果出現「連不上裝置」或要你設定 Wi-Fi，不用理它，直接拔掉就好：這個韌體不用 Wi-Fi，燒好後它會變成隨身碟＋鍵盤，網頁就認不得它了。
選裝置時清單是空的：拔掉，確認一直按住按鈕再插一次。

一般版從 …/USB-AGENT/main/、開發版從 …/USB-AGENT/main/dev/ 下載軟體。開發版的電腦檔案存取：系統資料夾不能動；搬運一定先問你、確認內容一樣才刪原檔。韌體還沒有在實機上測過。
